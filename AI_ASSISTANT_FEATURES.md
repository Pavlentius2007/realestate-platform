# 🤖 Умный ИИ-Ассистент по недвижимости

## 🎯 Что это такое?

Новый интеллектуальный помощник, который понимает естественную речь и помогает найти идеальную недвижимость в Паттайе. Пользователи могут просто описать свои потребности обычными словами, а ИИ найдет подходящие варианты и даст экспертные рекомендации.

## ✨ Ключевые возможности

### 🗣️ Понимание естественной речи
- Анализирует сообщения на русском языке
- Извлекает параметры поиска из обычного текста
- Понимает сложные запросы вроде "Нужна квартира до 5 млн бат в центре Паттайи для постоянного проживания, 2 спальни, с бассейном"

### 🔍 Умный поиск
- **Бюджет**: распознает числа с единицами (млн, тыс, k, баты)
- **Тип недвижимости**: квартира, кондо, вилла, таунхаус, студия, пентхаус
- **Районы**: центр, север, юг, Джомтьен, Наклуа, Вонгамат, Пратамнак
- **Количество спален**: автоматическое извлечение из текста
- **Площадь**: поиск по минимальной площади
- **Удобства**: бассейн, спортзал, парковка, охрана и др.
- **Вид**: море, город, горы, сад
- **Цель покупки**: инвестиции, жизнь, отдых

### 🧠 Интеллектуальный анализ
- Анализирует найденные объекты
- Сравнивает цены с бюджетом пользователя
- Определяет популярные типы и районы
- Дает персональные рекомендации на основе цели покупки

### 💬 Живое общение
- Современный чат-интерфейс
- История диалога с пользователем
- Сохранение предпочтений в сессии
- Быстрые запросы для популярных сценариев

### 📊 Аналитика и рекомендации
- Статистика по найденным объектам
- Топ-3 рекомендации с обоснованием
- Предложения при отсутствии результатов
- Советы по корректировке параметров поиска

## 🛠️ Техническая реализация

### Архитектура
- **Backend**: FastAPI + SQLAlchemy + PostgreSQL
- **Frontend**: Vanilla JavaScript + Tailwind CSS
- **ИИ-логика**: Python с регулярными выражениями и NLP-анализом

### Новые модели данных
- **ChatSession**: сессии чата с предпочтениями пользователей
- **ChatMessage**: история сообщений и метаданные поиска

### API эндпоинты
- `GET /ru/ai-chat` - страница чата
- `POST /ru/ai-chat` - обработка сообщений

## 🎨 Пользовательский интерфейс

### Основные элементы
- **Чат**: современный интерфейс с пузырьками сообщений
- **Быстрые запросы**: готовые кнопки для популярных запросов
- **Статистика**: показ популярных запросов
- **Советы**: подсказки по использованию
- **Результаты**: красивые карточки найденных объектов

### Функциональность
- Автоматическая прокрутка чата
- Индикатор загрузки
- Адаптивный дизайн для мобильных
- Плавные анимации и переходы

## 🔮 Примеры использования

### Базовый поиск
```
Пользователь: "Ищу квартиру до 3 млн бат в Джомтьене"
ИИ: "🤖 Отлично! Я нашел 12 подходящих вариантов недвижимости.
💰 Хорошие новости! Средняя цена (2,100,000 ฿) ниже вашего бюджета.
📍 Самый популярный район: Джомтьен (8 объектов)"
```

### Инвестиционный запрос
```
Пользователь: "Нужна вилла с бассейном для инвестиций"
ИИ: "🤖 Отлично! Я нашел 5 подходящих вариантов недвижимости.
💼 Для инвестиций рекомендую обратить внимание на новостройки с хорошей инфраструктурой."
```

### Комплексный поиск
```
Пользователь: "Хочу пентхаус с видом на море, 3 спальни, бюджет до 10 млн"
ИИ: Анализирует все параметры и находит подходящие варианты с детальными рекомендациями
```
