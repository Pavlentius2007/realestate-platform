# Транскрибатор

Программа для преобразования аудиофайлов в текст с поддержкой русского и английского языков.

## Возможности

- Поддержка форматов MP3, WAV, M4A
- Автоматическое определение языка (русский/английский)
- Вывод в форматах TXT и SRT (субтитры)
- Поддержка разных моделей Whisper (tiny до large)
- Простой CLI интерфейс

## Установка

1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-репозиторий/transcriber.git
   cd transcriber
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

### Базовое использование

```bash
python src/transcriber.py audio.mp3
```

Это создаст файл `audio.txt` с транскрибированным текстом.

### Дополнительные опции

```bash
# Использование конкретной модели
python src/transcriber.py audio.mp3 --model large

# Сохранение в формате субтитров
python src/transcriber.py audio.mp3 --format srt

# Указание пути для сохранения
python src/transcriber.py audio.mp3 --output result.txt
```

### Доступные модели

- `tiny`: Самая быстрая, но менее точная
- `base`: Хороший баланс скорости и точности (по умолчанию)
- `small`: Лучше качество, медленнее
- `medium`: Высокое качество
- `large`: Наилучшее качество, но требует больше ресурсов

## Форматы вывода

### TXT формат
Простой текстовый файл с транскрибированным текстом.

### SRT формат
Файл субтитров с временными метками, который можно использовать в видеоплеерах.

## Требования к системе

- Python 3.8 или выше
- 4GB RAM минимум (8GB рекомендуется для large модели)
- CUDA-совместимая видеокарта (опционально, для ускорения)
