# 💰 Инвестиционный калькулятор Sianoro

Интерактивный калькулятор для расчёта инвестиционной привлекательности покупки недвижимости в Таиланде.

## 🚀 Основные возможности

### ✅ Функциональность
- **Мультивалютность**: THB, USD, RUB, CNY с автоматическим обновлением курсов
- **Реальные расчёты**: учёт всех затрат и доходов
- **Визуализация**: график прироста цены недвижимости
- **PDF отчёты**: детальный отчёт с возможностью скачивания
- **Предустановленные сценарии**: быстрый расчёт для студии, 1BR, 2BR
- **Мобильная адаптивность**: оптимизирован для всех устройств

### 📊 Расчётные параметры

#### Вводные данные:
- Стоимость квартиры (в выбранной валюте)
- Площадь квартиры (м²)
- Депозит (по умолчанию 100,000 THB)
- Контрактный платёж (% от стоимости, по умолчанию 35%)
- Рассрочка на строительство (% от стоимости, по умолчанию 15%)
- Расходы на оформление (% от стоимости, по умолчанию 1.1%)
- Sinking Fund (единовременный платёж)
- Maintenance Fee (ежегодное обслуживание)
- Прогноз роста цены (% в год, по умолчанию 12%)
- Срок до окончания строительства (лет, по умолчанию 3)
- Доходность от аренды (% в год, по умолчанию 7%)

#### Результаты расчёта:
- **Всего инвестировано**: общая сумма вложений до окончания строительства
- **Будущая цена**: прогнозируемая стоимость через N лет
- **Прибыль**: доход от роста цены недвижимости
- **Доход от аренды**: общий доход от сдачи в аренду за весь период
- **Годовая доходность (ROI)**: процент возврата инвестиций в год
- **Общая доходность (ROI)**: общий процент возврата с учётом роста цены и аренды
- **Цена за м²**: стоимость квадратного метра

## 🎯 Использование

### Открытие калькулятора
Калькулятор доступен:
- На главной странице (кнопка "Рассчитать инвестиции")
- В каталоге недвижимости
- В каталоге новостроек
- Через навигационное меню

### Быстрые сценарии
Используйте предустановленные сценарии для быстрого расчёта:
- **Студия (25м²)**: типичная студия с базовыми параметрами
- **1 спальня (40м²)**: однокомнатная квартира
- **2 спальни (65м²)**: двухкомнатная квартира

### Смена валюты
Выберите нужную валюту из выпадающего списка. Курсы обновляются автоматически через API.

### Экспорт результатов
Нажмите кнопку "Скачать PDF отчёт" для получения детального отчёта с расчётами.

## 🔧 Техническая реализация

### Файловая структура
```
static/
├── css/investment_calculator.css    # Стили калькулятора
```

### Технологии
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Графики**: Canvas API
- **PDF**: jsPDF библиотека
- **API валют**: exchangerate.host
- **Стили**: Tailwind CSS совместимые классы

### Интеграция
Калькулятор интегрирован как модальное окно и подключается к страницам:
- `landing.html` - главная страница
- `properties_catalog.html` - каталог недвижимости
- `projects_catalog.html` - каталог новостроек

## 🌐 API интеграция

### Курсы валют
Используется бесплатный API `exchangerate.host`:
```javascript
fetch('https://api.exchangerate.host/latest?base=THB&symbols=USD,RUB,CNY')
```

### Fallback
При недоступности API используются значения по умолчанию:
- THB: 1 (базовая валюта)
- USD: 0.028
- RUB: 2.5
- CNY: 0.2

## 📈 Формулы расчёта

### Основные расчёты:
```javascript
// Общие инвестиции
totalInvested = deposit + contractAmount + installmentAmount + registrationAmount + sinking

// Будущая цена
futurePrice = currentPrice * (1 + growthRate)^years

// Прибыль от роста
profit = futurePrice - totalInvested

// Доход от аренды
totalRentIncome = futurePrice * rentYield * years

// ROI
roiTotal = ((profit + totalRentIncome) / totalInvested) * 100
```

Калькулятор выводит отладочную информацию:
