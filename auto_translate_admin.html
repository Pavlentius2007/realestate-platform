⚙️ Настройки автоматического перевода
Важно: Автоматический перевод использует машинное обучение. Для критически важного контента рекомендуется проверка переводов вручную.
Готово к работе! Система автоматических переводов настроена и готова к использованию. Новые статьи и объекты недвижимости будут автоматически переводиться на 3 языка: английский, тайский и китайский.
📋 Инструкция по настройке
  1. Установите зависимости: 
    pip install googletrans==3.1.0a0 asyncpg
  2. Выполните SQL-скрипт в PGAdmin4:

    Запустите файл setup_translation_hooks.sql для создания триггеров автоматического перевода

  3. Подключите роутер к основному приложению
  4. Настройте фоновые задачи для обработки очереди переводов
