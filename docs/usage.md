# 📖 Использование Транскрибатора

## Быстрый старт

### Базовое использование

```bash
python src/transcriber.py --file audio.mp3
```

Эта команда:
- Автоматически определит язык аудио
- Использует модель "base" (баланс скорости и качества)
- Сохранит результат в формате TXT
- Создаст файл `audio_transcript.txt` в той же папке

### Полный синтаксис

```bash
python src/transcriber.py [ОПЦИИ] --file ПУТЬ_К_ФАЙЛУ
```

## Параметры командной строки

### Обязательные параметры

| Параметр | Описание | Пример |
|----------|----------|--------|
| `-f, --file` | Путь к аудиофайлу | `--file "audio.mp3"` |

### Опциональные параметры

| Параметр | Описание | По умолчанию | Пример |
|----------|----------|--------------|--------|
| `-l, --language` | Язык аудио | `auto` | `--language ru` |
| `-o, --output-format` | Формат вывода | `txt` | `--output-format both` |
| `-d, --output-dir` | Директория для сохранения | папка с файлом | `--output-dir ./output` |
| `-m, --model` | Модель Whisper | `base` | `--model large` |
| `-v, --verbose` | Подробный вывод | `False` | `--verbose` |

## Поддерживаемые языки

| Код | Язык | Описание |
|-----|------|----------|
| `auto` | Автоопределение | Автоматически определяет язык |
| `ru` | Русский | Принудительно использует русский |
| `en` | Английский | Принудительно использует английский |

## Модели Whisper

| Модель | Размер | Скорость | Качество | Память |
|--------|--------|----------|----------|--------|
| `tiny` | 39 MB | Очень быстро | Низкое | ~1 GB |
| `base` | 74 MB | Быстро | Среднее | ~1 GB |
| `small` | 244 MB | Средне | Хорошее | ~2 GB |
| `medium` | 769 MB | Медленно | Отличное | ~5 GB |
| `large` | 1550 MB | Очень медленно | Лучшее | ~10 GB |

**Рекомендации:**
- Для быстрой обработки: `tiny` или `base`
- Для качественной транскрибации: `small` или `medium`
- Для максимального качества: `large`

## Форматы вывода

| Формат | Описание | Расширение файла |
|--------|----------|------------------|
| `txt` | Только текст | `.txt` |
| `srt` | Субтитры с временными метками | `.srt` |
| `both` | И текст, и субтитры | `.txt` + `.srt` |

## Примеры использования

### 1. Базовое использование

```bash
# Транскрибация с автоопределением языка
python src/transcriber.py -f "audio.mp3"

# Транскрибация на русском языке
python src/transcriber.py -f "audio.wav" -l ru

# Транскрибация с субтитрами
python src/transcriber.py -f "audio.m4a" -o srt
```

### 2. Продвинутое использование

```bash
# Использование большой модели для лучшего качества
python src/transcriber.py -f "audio.mp3" -m large -o both

# Сохранение в определенную директорию
python src/transcriber.py -f "audio.wav" -d "./transcripts" -o txt

# Подробный вывод для отладки
python src/transcriber.py -f "audio.m4a" -v -l en -m small
```

### 3. Обработка множественных файлов

```bash
# Windows
for %f in (*.mp3) do python src/transcriber.py -f "%f" -o both

# Linux/macOS
for file in *.mp3; do
    python src/transcriber.py -f "$file" -o both
done
```

### 4. Пакетная обработка с разными настройками

```bash
# Обработка русских файлов
python src/transcriber.py -f "russian_audio.mp3" -l ru -m medium -o both

# Обработка английских файлов
python src/transcriber.py -f "english_audio.wav" -l en -m base -o txt
```

## Поддерживаемые форматы аудио

| Формат | Расширение | Описание |
|--------|------------|----------|
| MP3 | `.mp3` | Самый распространенный |
| WAV | `.wav` | Без сжатия, высокое качество |
| M4A | `.m4a` | Apple формат |
| FLAC | `.flac` | Без потерь |
| OGG | `.ogg` | Открытый формат |

## Структура выходных файлов

### Текстовый файл (.txt)
```
Это пример транскрибированного текста.
Каждое предложение записывается с новой строки.
Пунктуация сохраняется согласно речи.
```

### Файл субтитров (.srt)
```
1
00:00:00,000 --> 00:00:03,500
Это пример транскрибированного текста.

2
00:00:03,500 --> 00:00:07,200
Каждое предложение записывается с новой строки.

3
00:00:07,200 --> 00:00:10,800
Пунктуация сохраняется согласно речи.
```

## Логирование

Программа создает подробные логи в папке `logs/`:

- `transcriber_YYYYMMDD_HHMMSS.log` - основной лог
- Содержит информацию о процессе обработки
- Включает ошибки и предупреждения
- Показывает время выполнения

### Уровни логирования

- **INFO**: Основная информация о процессе
- **WARNING**: Предупреждения (не критичные)
- **ERROR**: Ошибки (критичные)
- **DEBUG**: Отладочная информация (только с `--verbose`)

## Производительность

### Рекомендации по оптимизации

1. **Используйте подходящую модель:**
   - Для быстрой обработки: `tiny` или `base`
   - Для качественной транскрибации: `small` или `medium`

2. **Оптимизируйте аудиофайлы:**
   - Используйте монофоническое аудио
   - Частота дискретизации 16kHz
   - Формат WAV для лучшего качества

3. **Системные требования:**
   - Минимум 4 GB RAM
   - SSD для быстрого доступа к файлам
   - GPU для ускорения (опционально)

### Примерное время обработки

|--------------|--------|-----|-----|
| 1 минута | tiny | 30 сек | 10 сек |
| 1 минута | base | 60 сек | 20 сек |
| 1 минута | small | 120 сек | 40 сек |
| 1 минута | medium | 300 сек | 100 сек |
| 1 минута | large | 600 сек | 200 сек |

## Устранение проблем

### Частые ошибки

1. **"File not found"**
   - Проверьте путь к файлу
   - Убедитесь что файл существует

2. **"Unsupported format"**
   - Проверьте расширение файла
   - Конвертируйте в поддерживаемый формат

3. **"Out of memory"**
   - Используйте модель меньшего размера
   - Закройте другие приложения
   - Увеличьте объем RAM

4. **"FFmpeg not found"**
   - Установите FFmpeg
   - Добавьте в PATH

## Интеграция с другими инструментами

### Использование в скриптах

```python
from src.transcriber import Transcriber

transcriber = Transcriber(verbose=True)
success = transcriber.transcribe_file(
    file_path="audio.mp3",
    language="auto",
    output_format="both",
    model="base"
)
```

### Автоматизация

```bash
# Обработка всех файлов в папке
find . -name "*.mp3" -exec python src/transcriber.py -f {} -o both \;

# Планировщик задач (cron)
0 2 * * * cd /path/to/transcriber && python src/transcriber.py -f new_audio.mp3
```
