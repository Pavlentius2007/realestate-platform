# Структура тестов

- `unit/` — unit-тесты (юнит-тесты для моделей, сервисов, утилит)
- `integration/` — интеграционные тесты (API, взаимодействие компонентов)
- `e2e/` — end-to-end тесты (пользовательские сценарии)
- `security/` — тесты безопасности
- `performance/` — нагрузочные тесты
- `fixtures/` — фикстуры и тестовые данные
- `config/` — тестовые конфиги и вспомогательные файлы
- `conftest.py` — глобальные фикстуры pytest
- `pytest.ini` — конфиг pytest

## Запуск тестов

```bash
pytest tests/
```

## Примечания
- Для интеграционных тестов требуется рабочий FastAPI app и тестовая база.
- Для e2e тестов требуется Selenium и браузер.
- Все тестовые данные изолированы от боевой базы.
