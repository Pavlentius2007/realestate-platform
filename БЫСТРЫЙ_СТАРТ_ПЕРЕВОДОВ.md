# 🚀 Быстрый старт: Автоматические переводы

## 📦 Установка (2 минуты)

### 🪟 Windows (простой способ):
```bash
# Запустите готовый скрипт установки
install_dependencies.bat
```

### 🐧 Linux/Mac или ручная установка:
```bash
# 1. Установите ВСЕ зависимости проекта (включая FastAPI, googletrans и др.)
pip install -r requirements.txt

# 2. Запустите создание SQL настроек
python auto_translate.py
```

> ⚠️ **Важно:** Убедитесь, что установлены ВСЕ зависимости из `requirements.txt`. Иначе могут возникать ошибки типа "Package fastapi is not installed".

## 🗄️ Настройка БД (3 минуты)

1. Откройте **PGAdmin4**
2. Выполните скрипт **`setup_translation_hooks.sql`**
3. Готово! Триггеры автоматического перевода установлены

## 🔗 Подключение API ✅

API автопереводов уже подключен в `backend/main.py`! Никаких дополнительных действий не требуется.

## ✅ Тестирование

```bash
# Тест переводов
python test_auto_translate.py

# Проверка API (после запуска сервера)
curl http://localhost:8002/api/translate/languages
```

## 🎯 Как работает

### **Автоматически:**
- Новый объект добавлен в БД → автоматически переводится на 3 языка ✨
- Триггер PostgreSQL добавляет в очередь переводов
- Фоновый процесс переводит через Google Translate

### **Вручную через API:**
```javascript
// Перевод текста
fetch('/api/translate/text', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
        text: "Красивая квартира с видом на море",
        target_language: "en"
    })
});

// Перевод статьи
fetch('/api/translate/article/123', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
        target_languages: ["en", "th", "zh"]
    })
});
```

## 🛠️ Решение проблем

### ❌ "Package fastapi is not installed"
```bash
# Windows: запустите скрипт автоустановки
install_dependencies.bat

# Или вручную:
pip install -r requirements.txt
```

### ❌ "googletrans not found"  
```bash
# Решение: проверьте версию
pip install googletrans==3.1.0a0 --force-reinstall
```

### ❌ Проблемы с виртуальным окружением
```bash
# Создайте новое виртуальное окружение
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```
