## 🔍 Диагностика

### Проверка структуры БД
```sql
SELECT column_name, data_type, is_nullable, column_default
FROM information_schema.columns 
WHERE table_name = 'users' 
ORDER BY ordinal_position;
```

### Проверка пользователей
```sql
SELECT COUNT(*) as total_users FROM users;
SELECT COUNT(*) as null_names FROM users WHERE name IS NULL;
SELECT COUNT(*) as null_passwords FROM users WHERE hashed_password IS NULL;
```

## 🆘 Если что-то не работает

### Ошибка "столбец не существует"
- Убедитесь, что SQL-скрипт выполнился полностью
- Проверьте структуру таблицы users в PGAdmin4

### 404 ошибки управления пользователями
- Перезапустите сервер после исправления модели User
- Проверьте, что нет ошибок импорта в логах

### Ошибки переводов
- Переключение языков работает через `/lang/en`, `/lang/ru`, `/lang/th`, `/lang/zh`
- Или через параметры URL: `/en`, `/ru`, `/th`, `/zh`
